# Leukemia CNN+GNN Notebooks

This repository contains only the two CNN+GNN experiments and their required support code.

| Notebook | Dataset | Backbone | Evaluation |
| --- | --- | --- | --- |
| [03_hybrid_cnn_gnn.ipynb](notebooks/03_hybrid_cnn_gnn.ipynb) | ALL-IDB1 | InceptionV3 + dynamic GNN | Five duplicate-aware stratified image folds |
| [05_kaggle_cnn_gnn.ipynb](notebooks/05_kaggle_cnn_gnn.ipynb) | C-NMC | Three-fold SE-InceptionV3 + dynamic GNN ensemble | Predefined subject-disjoint folds and official 1,867-image test |

## Measured results

The completed ALL-IDB1 run achieved **98.15% accuracy**, 98.13% balanced accuracy and 0.9941 macro ROC-AUC. Its compact paper metrics and plots are versioned under [`reports/allidb1_inception_v3_dynamic_gnn`](reports/allidb1_inception_v3_dynamic_gnn).

The completed C-NMC ensemble achieved **78.47% accuracy**, 73.68% balanced accuracy and 0.8621 macro ROC-AUC on the official preliminary test set. It did not reach the 93% target. Its compact report is versioned under [`reports/cnmc_se_inception_v3_gnn_3fold`](reports/cnmc_se_inception_v3_gnn_3fold).

Large checkpoints, datasets, embeddings, per-image predictions and generated working results are intentionally excluded from Git. They can be regenerated by running the notebooks.

## Model choices

Both datasets use InceptionV3 + dynamic GNN. C-NMC adds squeeze-and-excitation channel attention and averages three models trained with the dataset’s predefined subject-disjoint folds. Its preprocessing uses a consistent center crop and mild augmentation, followed by validation calibration and patient-neighborhood smoothing.

- [ALL-IDB1 backbone comparison](https://onlinelibrary.wiley.com/doi/10.1155/je/7765920)

## Run in VS Code

Open a notebook, select `.venv/bin/python`, and run its training cell. Nothing trains automatically.

- ALL-IDB1: 299px, batch size 4, five folds, maximum 10 epochs per fold.
- C-NMC: three folds, 299px, batch size 8, maximum 15 epochs per fold with patience 5. It prints progress every 100 batches.

The ALL-IDB1 protocol is duplicate-aware image-level cross-validation and should be reported with that description. The C-NMC protocol preserves patient separation and uses the official preliminary test labels.

## Checks without epochs

```bash
.venv/bin/python -m pytest -q tests/test_hybrids.py
```

The checks cover notebook syntax, model forward/backward paths, checkpoint loading, both datasets and patient separation. They do not run training epochs.
